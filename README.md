# 🎨 D2B Gourmet — Branding, Design System & IA

Projeto de **branding, identidade visual e design system** desenvolvido para a **D2B Gourmet**, com foco na construção de uma marca consistente, memorável e alinhada ao posicionamento do negócio.

Este projeto contempla desde a criação do **logotipo e identidade visual**, até a definição de **tipografia, paleta cromática, aplicações da marca e diretrizes de uso**, organizadas em um **manual de identidade visual**.

💡 **Destaque:** anos depois, o projeto evoluiu para uma iniciativa conectada à tecnologia, através do desenvolvimento de um **Agente de Vendas com IA para a D2B Gourmet**, criando uma ponte entre **branding, produto e inteligência artificial**.

---

## ✨ Objetivo do Projeto

Construir um sistema visual consistente que garantisse:

* reconhecimento de marca
* padronização visual
* coerência entre diferentes materiais
* fortalecimento do posicionamento da empresa
* escalabilidade da comunicação visual

---

### 🎯 Identidade da Marca

* Criação do logotipo

### 🎨 Sistema Visual

* Variações da marca

* Aplicações corretas e incorretas

* Fontes principais e secundárias
* Diretrizes de aplicação

### 🖥️ Aplicações Visuais

* Papelaria
* Cartão de visita
* Embalagens
* Uniformes
* Materiais institucionais
